# ChIP-seq Large Margin Visualization

Animint2 port of the max-margin supervised penalty learning visualization
for ChIP-seq peak detection.

**Live visualization:** https://ANAMASGARD.github.io/chip-seq-large-margin/

**Original paper visualization:**
https://rcdata.nau.edu/genomic-ml/animint-gallery/2016-11-10-Max-margin-supervised-penalty-learning-for-peak-detection-in-ChIP-seq-data/

**Gallery PR:** https://github.com/animint/gallery/pull/51

Data is downloaded automatically from NAU genomic-ml servers on first run.
